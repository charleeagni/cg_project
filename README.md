# Effects of plastic on the environment

A 2D OpenGL/GLUT animation made for a sixth-semester computer graphics project.

## Run it

The project needs a C++ compiler, OpenGL, and GLUT.

On macOS, the required frameworks are included with Xcode Command Line Tools:

```sh
xcode-select --install
make run
```

On Ubuntu or Debian, install FreeGLUT first:

```sh
sudo apt install build-essential freeglut3-dev
make run
```

Use `A` and `D` to move between scenes. Press `Q` or Escape to quit.

Run `make clean` to remove compiled files.
